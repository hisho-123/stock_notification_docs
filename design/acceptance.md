# 受け入れ条件・検証シナリオ

製品実装時の受け入れ条件と、本仕様書・HTMLを確認する条件を定義する。通知・外部価格取得はモックを用い、実ユーザーへの送信なしで検証する。例示する価格は仮の値。

## 通知・同時処理・障害

| ID | 条件 | 期待結果 |
| --- | --- | --- |
| M-01 | H=100、P=90.0001と90 | 前者は未通知、後者は10%。表示丸めに判定が影響されない |
| M-02 | H=100、P=73、未通知 | 25%について1通のみ、L=25 |
| M-03 | 20%通知後に95→80→100 | 再通知なし、L=20保持 |
| M-04 | 20%通知後に110→99 | 110でH更新・L=null、99で10%通知 |
| M-05 | L=20、設定を[5,15,25]へ変更、P=80→75 | 80は通知なし、75で25%通知 |
| M-06 | 下落通知のLINE送信失敗 | L保持、取得価格・日時とNOTIFICATION_FAILED保存。失敗後の再送などの追加処理なし。翌日の日次実行で最新価格から通常の通知条件を再判定 |
| M-07 | FMP失敗 | 価格・最高値・通知済み率保持、確認時刻とPRICE_FETCH_FAILEDを保存。他銘柄処理継続、終了1 |
| M-08 | 鮮度確認を通過して正常処理へ復帰 | last_error_code=nullに戻る。古いデータ検知や手動再開だけでは解消しない |
| M-09 | DB保存失敗・接続断 | 対象のトランザクションをロールバック、終了1。接続維持なら他対象を続行、接続断なら再接続せず終了。処理済み変更は維持。LINE受付後なら重複リスクあり |
| M-10 | 重複実行を避ける運用 | スケジューラと手動実行が重ならない手順を確認。アプリの排他制御や重複時の正常スキップを前提にしない |
| M-11 | 処理前の存在・有効状態の再確認で停止・削除済み | 保存・通知せずスキップする。確認後の競合については整合性を保証しない |
| M-12 | 対象読み出し後の価格取得中に停止→再開 | 再確認時に有効なら同じ実行で処理・通知され得る。監視中の操作は避ける。停止・削除完了後の送信抑止も保証しない |
| M-13 | 実行途中に共通設定を変更 | 実行開始時の配列を全対象で使用。次回から新配列 |
| M-14 | 登録0件・休日の鮮度確認を通過した同じ価格 | 正常終了0、不要な通知なし |
| M-15 | データの経過時間が863,999秒、864,000秒、864,001秒 | 前者だけ通常判定。後二者は古いデータとして扱う。土日・祝日も同じ |
| M-16 | 古いデータを検知、停滞通知成功 | 下落判定・最高値更新なし。価格・最高値・取得日時・L保持、確認日時更新、enabled=false、PRICE_DATA_STALE。停滞通知1通、他対象続行、終了1 |
| M-17 | 古いデータを検知、停滞通知失敗→翌日も古い（連続） | 価格・最高値・取得日時・L保持、確認日時とNOTIFICATION_FAILED保存、監視中を維持。実行内の再送なし。翌日再取得して停滞通知1回、成功時だけ停止。各実行は終了1 |

## 認証・運用

| ID | 条件 | 期待結果 |
| --- | --- | --- |
| S-01 | 未認証・期限ちょうど・期限後 | 全保護APIは401。画面はログインへ遷移 |
| S-02 | ログイン成功・ログアウト | Cookie属性・24時間期限を満たす。ログアウト後の旧Cookieは使用不可 |
| S-03 | 他Origin・Origin欠落、変更系CSRF欠落/不一致 | 403、DB変更なし。ログインもOrigin確認 |
| S-04 | 15分内に5回認証失敗後の再試行 | 429、Retry-After。窓の経過後は再試行可能 |
| S-05 | JSON以外・未知項目・不正ID | 415または400。処理しない |
| S-06 | 秘密値を含む外部障害 | 応答・ログにキー、トークン、SQL、レスポンス本文なし |
| S-07 | スケジュール設定 | 日本時間07:00に起動。UTCなら前日22:00との対応を確認 |
| S-08 | 設定欠落・DB接続不可 | 実行を失敗させ、既定値で運用を継続しない |
| S-09 | セッション掃除・DB復元 | 期限切れは未掃除でも拒否。復元後は全セッション削除 |
| S-10 | 一覧・通知設定からログアウト | 通知設定の未保存変更は破棄確認し、取消時はAPIを呼ばない。POST /auth/logoutの成功・401でデータとトークンを破棄してログインへ。通信失敗時はエラーを表示し、画面と編集内容を保持 |
