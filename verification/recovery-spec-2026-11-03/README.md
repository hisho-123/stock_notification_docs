# 回復通知の仕様・画面見本の検証（2026-11-03）

対象は仕様書・OpenAPI・静的HTML見本。製品コード・DBマイグレーションの変更や、価格判定・LINE送信の実装テストは含まない。

| 対象 | 方法・結果 |
| --- | --- |
| 通知規則 | 基準価格と同値は回復なし、全水準を1通、部分回復・再下落・設定削除・失敗・ブロック・新高値の説明を文書間で照合。受け入れ条件REC-01〜20を追加 |
| OpenAPI | openapi-spec-validatorで3.0.3として合格。9操作・10スキーマ・内部参照100件を確認 |
| 例示・サンプル | openapi-schema-validatorでOpenAPI内の例示34件、API説明のJSON5件、HTML用6銘柄と通知設定を検証し合格 |
| 公開APIの形状 | 基準版HEADの定義と、説明・例示・版番号を除いて比較し一致。回復待ちの公開項目・新エンドポイントなし |
| 文書・HTML | 相対リンクの存在、3画面のID重複なし、UI仕様の要素ID、一覧ソート値とOpenAPIの対応を確認し合格。件数は静的検証JSONを参照 |
| JavaScript・差分 | node --checkでsample-data.js・preview.jsを構文確認。git diff --checkはエラーなし |
| 表示 | Chromium、PC 1440×900・スマートフォン390×844で一覧・通知設定を確認。両画面の全6表示状態でページの横はみ出しなし。一覧テーブルのみスマートフォンで横スクロール |
| 表示文言・操作 | 新しい回復ルール・一覧見出し、最終下落通知率の昇降順とnull末尾、通知率の削除・追加・保存を確認。表示と合わせ44確認が成功、JavaScript実行例外0件 |
| 目視確認 | 通常表示の4画像で文字の重なり・欠け・ページの横はみ出しなし |

Pythonの検証ライブラリは一時ディレクトリへ取得した。ローカルHTTPサーバーとブラウザでHTMLを開き、実FMP・LINE・製品APIへは接続していない。初回のfavicon取得404はJavaScript実行例外と区別した。
