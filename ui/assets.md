# 監視対象一覧画面（UI-02）

- アプリURL：`/assets`（`/`からも遷移）
- 画面イメージ：[asset/assets.html](../asset/assets.html)
- 機能：[機能仕様](../design/features.md)、API：[API仕様](../api/README.md)

## 要素・挙動

| HTML要素ID | 要素 | 挙動 |
| --- | --- | --- |
| settings-link | 通知設定 | `/settings/notifications`へ遷移 |
| logout-button | ログアウト | POST /auth/logout。成功・401でデータとトークンを破棄し`/login`へ。通信失敗はエラー表示して画面を保持 |
| code-input | 銘柄コード | 必須、正規化後1〜64文字。例AAPL・^GSPC。空白・制御文字不可 |
| add-form / add-button | 追加 | Enter・ボタンでPOST /assets。処理中は追加欄を無効化して「取得中…」。成功時は入力を消去して現在の検索・ソートで一覧再取得 |
| add-error | 追加エラー | 重複・取得不可・通信失敗を表示し入力を保持 |
| search-input / search-form | 検索 | 最大200文字。Enterまたは検索ボタンでqを適用。空文字で検索すると解除。IME入力中は送信しない |
| refresh-button | 一覧更新 | 現在の検索・ソートでGET /assets。外部価格は再取得しない |
| asset-table | 一覧 | 列見出しのボタンで昇順・降順を切り替え、APIを再取得。同じ列は順序反転、新しい列は昇順。aria-sortで状態を示す |
| result-count | 件数 | 検索結果件数。ページングなし |
| list-error / list-status | 状態表示 | 通信失敗はバナー＋再試行。再取得失敗時は直前の一覧を残し「更新できませんでした」と表示 |
| notice | 操作結果 | aria-live。追加・停止・再開・削除結果を表示 |
| delete-dialog | 削除確認 | 名称・コードと再登録時のリセットを説明。取消・Escで閉じる。開いたときに取消へフォーカス、閉じたときに操作元へ戻す |
| delete-confirm / delete-cancel | 削除・取消 | 確定でDELETE /assets/{id}。処理中は無効化、失敗時はダイアログ内エラー。成功時は閉じて再取得 |

各行の停止・再開はPATCH /assets/{id}でmonitoring_enabledを変更する。行ごとに操作中は停止・再開・削除ボタンを無効化する。成功後に一覧を再取得。最高値・通知済み状態を保持し、再開による即時取得・通知はしない。監視処理との排他制御は行わず、監視中の停止・再開・削除は運用で避ける。実行中の停止→再開では同じ実行で通知され得る。手動再開ではエラーを保持する。

## 一覧の列

| 見出し | API項目・表示 |
| --- | --- |
| 銘柄 | codeとnameを2段表示。codeでソート。nameのソートは「ソート項目」セレクトから選択 |
| 監視開始後の最高値 | highest_value。価格は有効桁を保持し、桁区切り。値が長い場合も文字列を切り捨てない |
| 最終取得値 | latest_value。同じ表示形式 |
| 下落率 | decline_rateに%を付与、小数2桁 |
| 取得日時 | latest_fetched_atをYYYY/MM/DD HH:mm JSTで表示 |
| 監視状態 | monitoring_enabled=true「監視中」、false「停止中」。色に加えて文字で識別。停止中も過去の値を表示 |
| 通知済み率 | last_notified_threshold=null「未通知」、数値は%付き |
| 操作 | 停止または再開、削除 |

上記の列ソートに加え「ソート項目」セレクトでcreated_at（登録順）、nameを選択できる。`last_error_code`があれば銘柄欄に「価格取得に失敗」「LINE通知に失敗」「価格データが10日以上前」のいずれか、最終確認日時last_checked_atを表示する。日次処理では取得日時を失敗・停滞検知時刻に置き換えない。古い価格で新規登録した場合は取得完了日時を記録し、停止中と警告を併記する。登録成功の案内でも「価格データが10日以上前のため、停止状態で登録しました」と表示する。停滞通知成功による自動停止後も手動で再開でき、再開時に即時取得・通知は行わない。

スマートフォンはテーブル領域だけ横スクロールし、ページ全体の横はみ出しを防ぐ。全列・行操作を残す。価格の説明として「最高値は登録時と鮮度確認を通過した毎日の取得値から計算します。取得：毎日07:00 JST」を常時表示する。

## 初期表示・状態

セッション確認後、`GET /api/v1/assets?sort=created_at&order=asc`を呼ぶ。読み込み中は状態文を表示し、検索・更新を無効化する。データ未登録は追加を促し、検索結果なしは検索語の変更・解除を促す。古い検索要求の応答が新しい結果を上書きしないよう要求を取消または最新要求だけ反映する。

401は全画面共通でログインへ遷移。404の行操作は対象が削除済みとして一覧更新。通信中断などで登録成否が不明なら一覧更新して確認する。HTMLには通常・読み込み中・未登録・検索なし・通信失敗・追加中の切り替えと、サンプル銘柄の取得失敗・通知失敗・古い価格による停止状態を含める。古い価格での新規登録は、画面確認用の「古い価格で追加する」チェックを有効にして確認できる。これは実際のAPIの入力項目には追加しない。
